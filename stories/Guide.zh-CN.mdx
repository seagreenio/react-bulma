# React Bulma 使用指南

<p>

  </a>

适配现代 React 的 Bulma 组件库。

React Bulma 提供基于 Bulma 1.0.4 的 React 组件，使用时需要 React 17.0.2 或更高版本。

你可以在 React 中使用 Bulma 组件，通过属性调整外观、切换深浅主题。组件样式只在 `BulmaRoot` 内生效，也支持自定义 CSS 类名前缀。

你可以从[默认样式](#使用默认样式)开始，也可以[自定义前缀并构建样式](#自定义前缀并构建样式)，或直接了解如何[组合交互组件](#组合交互组件)。

## 安装

下面的命令在应用根目录运行，也就是应用 `package.json` 所在的目录。

你可以使用 npm 安装：

```sh
npm install @seagreenio/react-bulma
```

也可以使用 Bun：

```sh
bun add @seagreenio/react-bulma
```

## 使用默认样式

先在应用入口引入样式，只需引入一次：

```ts
import '@seagreenio/react-bulma/styles.css'
```

使用组件时，在外层包一层 `BulmaRoot`。不需要再引入 Bulma 的全局样式：

```tsx
import { Button, BulmaRoot, Field, Input, Label } from '@seagreenio/react-bulma'

export function App() {
  return (
    <BulmaRoot>
      <Field>
        <Label htmlFor="name">Name</Label>
        <Input id="name" name="name" placeholder="Your name" />
      </Field>
      <Button color="primary" helpers={{ mt: 4 }}>
        Save
      </Button>
    </BulmaRoot>
  )
}
```

组件默认使用 `rb-` 类名前缀和浅色主题。你可以在 `BulmaRoot` 上设置 `theme="dark"` 使用深色主题，或设置 `theme="system"` 跟随浏览器的配色偏好。嵌套的 `BulmaRoot` 可以分别设置主题和前缀。

样式依赖 CSS `@scope` 和容器查询，目标浏览器必须支持这两项功能。外层组件库样式不会进入嵌套的 Bulma 根组件，但页面自身的选择器和继承样式仍可能影响组件。

## 调整组件样式和属性

你可以用 `color` 设置按钮颜色，用 `rounded` 设置圆角。间距、文字样式、颜色、显示与隐藏，以及 Flex 布局都可以通过 `helpers` 设置。使用 TypeScript 时，编辑器会提示可用的属性和值。你也可以用 `className` 添加自己的 CSS 类：

```tsx
<Button
  color="primary"
  rounded
  helpers={{ mt: 0, px: 4 }}
  className="save-action"
>
  Save
</Button>
```

上面的 `mt: 0` 会生成 `rb-mt-0`，将上外边距设为 0。设置 `hidden: false` 时，不会添加隐藏类。你传入的 `className="save-action"` 会与组件的类名一起使用，保持原样，不会变成 `rb-save-action`。

给 `div`、`p` 等 HTML 元素设置相同的样式时，可以调用 `helpers()`，再把返回的类名传给 `className`。这个函数只生成类名，不会修改元素或插入 CSS。生成的类名默认以 `rb-` 开头；如果使用自定义 `BulmaUI` 中的 `helpers`，则会使用你配置的前缀：

```tsx
'use client'

import { BulmaRoot, helpers } from '@seagreenio/react-bulma'

export function Summary() {
  return (
    <BulmaRoot>
      <div
        className={helpers({
          display: 'flex',
          justifyContent: 'space-between',
          alignItems: 'center',
          p: 4,
        })}
      >
        <p className={helpers({ m: 0, textWeight: 'semibold' })}>Draft saved</p>
        <span className={helpers({ textColor: 'success' })}>Up to date</span>
      </div>
    </BulmaRoot>
  )
}
```

组件支持原生 HTML 属性、事件和 `ref`，也导出 `ButtonProps` 等对应的属性类型。对于带有外层容器的组件，下面的表格说明各项属性会作用在哪个元素上：

| 组件            | 原生属性、className、style 和 ref 传给谁 | helpers 和 wrapperProps 的作用位置                                    |
| --------------- | ---------------------------------------- | --------------------------------------------------------------------- |
| Input、Textarea | 原生 input 或 textarea                   | helpers 作用于控件本身                                                |
| Select          | 原生 select                              | helpers 和 wrapperProps 作用于外层包装元素                            |
| Checkbox、Radio | 原生 input                               | children 是标签内容，helpers 和 wrapperProps 作用于 label             |
| File            | 原生文件 input                           | children 是上传标签，helpers 和 wrapperProps 作用于文件控件的包装元素 |
| Image           | 原生 img，必须提供 alt                   | helpers 和 wrapperProps 作用于 figure                                 |
| FixedGrid       | 外层 fixed-grid div                      | gridProps 配置内层网格                                                |

`size` 用来调整组件大小，例如 `size="small"`。如果要设置 Input 或 Select 原生的 HTML `size` 属性，使用 `htmlSize`。Select 支持通过 `multiple` 开启多选。File 显示的文件名由 `filename` 决定，你可以在 `onChange` 中更新它。

需要提交表单时，在 Button 上设置 `type="submit"`，默认值是 `type="button"`。加载中的按钮会被禁用，并带有 `aria-busy` 属性。LinkButton 是链接，加载或禁用时无法跳转。禁用的分页链接和下拉菜单项也无法点击。Delete、TagDelete 和 NavbarBurger 都是按钮，默认带有供屏幕阅读器使用的标签。

## 自定义前缀并构建样式

如果要替换默认的 `rb-` 前缀，将同一份配置传给 `createBulma` 和 `buildStyles`。下面使用 `bui-` 作为前缀，生成 CSS 时选择 Bun 或 Node.js 中的一种即可：

```text
bulma.config.ts
scripts/
  styles.ts
  styles.mjs
src/
  bulma-ui.ts
  bulma.css
```

在应用根目录创建 `bulma.config.ts`：

```ts
export const bulmaConfig = { prefix: 'bui-' } as const
```

创建 `src/bulma-ui.ts`。其中 `../bulma.config` 指向根目录的 `bulma.config.ts`：

```ts
'use client'
import { createBulma } from '@seagreenio/react-bulma'
import { bulmaConfig } from '../bulma.config'

export const BulmaUI = createBulma(bulmaConfig)

const { BulmaRoot, Box, Button } = BulmaUI

export { BulmaRoot, Box, Button }
```

### 使用 Bun 生成 CSS

创建 `scripts/styles.ts`。其中 `../bulma.config` 同样指向根目录的配置：

```ts
import { buildStyles } from '@seagreenio/react-bulma/styles'
import { bulmaConfig } from '../bulma.config'

await Bun.write('src/bulma.css', await buildStyles(bulmaConfig))
```

在应用根目录运行，生成 `src/bulma.css`：

```sh
bun scripts/styles.ts
```

### 使用 Node.js 生成 CSS

如果使用 Node.js 22.18 或更高版本，可以改为创建 `scripts/styles.mjs`：

```js
import { writeFile } from 'node:fs/promises'
import { buildStyles } from '@seagreenio/react-bulma/styles'
import { bulmaConfig } from '../bulma.config.ts'

await writeFile('src/bulma.css', await buildStyles(bulmaConfig), 'utf8')
```

在应用根目录运行，生成同一个 `src/bulma.css`：

```sh
node scripts/styles.mjs
```

### 在应用中使用

每次构建应用前，先运行样式脚本。在应用入口引入生成的 CSS，替换默认样式。入口文件位于 `src/` 下时：

```ts
import './bulma.css'
```

接下来使用 `BulmaUI` 中的组件和 helpers：

```tsx
'use client'

import { BulmaUI } from './bulma-ui'

const { BulmaRoot, Button, helpers } = BulmaUI

export function App() {
  return (
    <BulmaRoot theme="dark">
      <p className={helpers({ mt: 4, textAlign: 'center', hidden: 'mobile' })}>
        Visible above the mobile breakpoint
      </p>
      <Button color="info">Save</Button>
    </BulmaRoot>
  )
}
```

在组件外创建 `BulmaUI`，避免每次渲染时重新创建。使用其中的组件和 helpers，并引入相同前缀的 CSS。前缀以小写英文字母开头、以 `-` 结尾，中间可以使用小写字母、数字和分隔单词的单个连字符，例如 `bui-`、`my-bui-`。同一页面可以使用多个前缀，也可以嵌套使用。

## 使用服务端渲染（SSR）

React Bulma 支持 React 17.0.2 及以上版本的服务端渲染，无需额外的打包配置。

## 使用 React Server Components

在 Next.js App Router 页面中直接导入组件。下面的页面不需要添加 `'use client'`：

```tsx
import { BulmaRoot, Box, Button } from '@seagreenio/react-bulma'

export default function Page() {
  return (
    <BulmaRoot>
      <Box>Content loaded on the server</Box>
      <Button color="primary" helpers={{ mt: 4 }}>
        Continue
      </Button>
    </BulmaRoot>
  )
}
```

使用 Next.js App Router 时，在根布局中引入样式：

```tsx
import '@seagreenio/react-bulma/styles.css'
```

### 自定义前缀

使用自定义前缀时，从前面创建的 `bulma-ui` 模块导入组件，并在根布局中引入生成的 CSS。

调用 `createBulma()`、`helpers()`，或使用事件处理函数、交互状态的文件，需要在顶部添加 `'use client'`。

## 组合交互组件

使用[自定义前缀配置](#自定义前缀并构建样式)中创建的 `BulmaUI`，可以这样组合一个设置弹窗：

```tsx
'use client'

import { BulmaUI } from './bulma-ui'

const {
  BulmaRoot,
  Modal,
  ModalTrigger,
  ModalCard,
  ModalCardHead,
  ModalTitle,
  ModalClose,
  ModalCardBody,
  ModalDescription,
  ModalCardFoot,
} = BulmaUI

export function Settings() {
  return (
    <BulmaRoot>
      <Modal>
        <ModalTrigger>Open settings</ModalTrigger>
        <ModalCard>
          <ModalCardHead>
            <ModalTitle>Settings</ModalTitle>
            <ModalClose variant="delete" />
          </ModalCardHead>
          <ModalCardBody>
            <ModalDescription>Update your preferences.</ModalDescription>
          </ModalCardBody>
          <ModalCardFoot>
            <ModalClose variant="button">Done</ModalClose>
          </ModalCardFoot>
        </ModalCard>
      </Modal>
    </BulmaRoot>
  )
}
```

你可以用 `open` 和 `onOpenChange` 控制弹窗的开关，或用 `defaultOpen` 设置初始状态。`closeOnEscape` 和 `closeOnOutsideClick` 分别控制按 Escape 和点击弹窗外部时是否关闭。每个弹窗都需要 `ModalTitle` 或 `aria-label`。弹窗会沿用所在 `BulmaRoot` 的主题；如果自定义挂载容器，也要把容器放在相同前缀的 `BulmaRoot` 内。

Dropdown 需要搭配 DropdownMenu 和 DropdownContent 使用，菜单会留在当前下拉菜单容器内。你可以用键盘切换菜单项，或设置 `as="a"` 将菜单项作为链接使用。禁用的菜单项仍可通过键盘获得焦点，但无法选中。

Tabs 由 TabsList、Tab 和 TabPanel 组成。每个 Tab 与对应的 TabPanel 使用相同的 `value`，可以是字符串或数字。默认用方向键移动焦点，再按 Enter 或空格键激活选项卡。在 TabsList 上设置 `activateOnFocus` 后，选项卡获得焦点时就会激活。禁用的选项卡可以获得键盘焦点，但不能激活。

Navbar 搭配 NavbarBrand、NavbarBurger、NavbarMenu、NavbarStart 和 NavbarEnd 组成导航栏。你可以用 `expanded` 和 `onExpandedChange` 控制移动端菜单的展开状态，或用 `defaultExpanded` 设置初始状态。按 Escape 会关闭菜单，并将焦点移回菜单按钮。NavbarDropdown 的 `trigger` 用来设置下拉菜单入口的文字或内容。

你可以结合 <a href="./?path=/docs/official-components-modal--docs" target="_top">Modal</a>、<a href="./?path=/docs/official-components-dropdown--docs" target="_top">Dropdown</a>、<a href="./?path=/docs/official-components-tabs--docs" target="_top">Tabs</a> 和 <a href="./?path=/docs/official-components-navbar--docs" target="_top">Navbar</a> 的示例，选择适合的组件组合方式。

## 选择布局

Columns 提供 12 列布局，可以随屏幕宽度调整。SmartGrid 根据 `minColumnWidth` 自动排列单元格，间距可以用 CSS 长度单位设置。FixedGrid 则可以为不同的容器宽度指定列数。

下面沿用[自定义前缀配置](#自定义前缀并构建样式)中的 `BulmaUI`，让网格随容器变宽，依次显示一列、两列和三列：

```tsx
'use client'

import { BulmaUI } from './bulma-ui'

const { BulmaRoot, FixedGrid, Cell, Box } = BulmaUI

export function Layout() {
  return (
    <BulmaRoot>
      <FixedGrid columns={{ mobile: 1, tablet: 2, desktop: 3 }}>
        <Cell>
          <Box>One</Box>
        </Cell>
        <Cell>
          <Box>Two</Box>
        </Cell>
        <Cell>
          <Box>Three</Box>
        </Cell>
      </FixedGrid>
    </BulmaRoot>
  )
}
```

Column 支持预设的列宽和偏移值，包括分数值，也可以按屏幕宽度分别设置。Cell 可以设置起始位置，以及跨越的行数或列数。

受 Bulma 1.0.4 限制，`offset="one-third"` 的偏移量为 `0.3333%`，Cell 的 `columnEnd` 和 `rowEnd` 不会改变网格位置。

标题组件的 `level` 决定 HTML 标题级别，数字 `size` 则独立控制显示大小。
